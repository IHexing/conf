# Shadowrocket 当前配置说明

更新：2026-10-29。维护与发布入口见 [README](../README.md)。

- 本地只保留 `apple-rules/custom.list` 和 `apple-rules/direct-custom.list` 两份个人覆盖规则。
- 自定义直连优先于自定义代理，之后才匹配社区规则；局域网与 STUN 保留原有策略。
- 海外 AI 直接订阅 VPSDance 的 `global.list`，不再维护本地聚合和清洗镜像。
- 国内通用直连使用 Loyalsoldier，IP 类匹配补充 `no-resolve`；手机仍保留普通 DNS 备用，不能据此保证所有 DNS 都经代理或加密。
- Apple 专用清单已移除，按社区与个人覆盖分流。
- 交易所台湾专线已按本轮确认取消，相关节点组与本地专用清单已移除。
- 默认未匹配流量仍使用 HOME；全局模式中手动选择其他节点的能力由客户端保留。

本轮只完成仓库准备与本地校验，实际配置更新、规则命中、出口和 DNS 需要手机验收。旧版报告中的评分、流量统计和“零泄漏”声明不作为当前验证结论。
